## 💡 为什么需要 Universal Novel Engine？

目前绝大多数 AI 辅助写作方案往往在写到 20-30 万字时遭遇**“断崖式崩盘”**：
1. **中途失忆与大纲塌方**：越写越散，前期大纲到中期彻底无法指导细纲；
2. **伏笔突兀如机械降神**：需要揭秘时，突然由反派或主角用两千字独白硬生生强行打补丁；
3. **严重词穷与套话复读**：满篇皆是*“深吸一口气”*、*“嘴角勾起一抹冷笑”*、*“倒吸一口凉气”*、*“夕阳如血”*；
4. **战力与经济通胀**：银两变成灵石，金钱失去意义；战力从刀剑搏杀膨胀为神光轰炸，失去微观打击触感。

**Universal Novel Engine** 彻底摒弃了传统的“单次提示词套皮”，将其重构为**“状态机驱动的三层记忆与防退化工业级管线”**，让大模型只负责文字表达，由外骨骼状态机严格控制逻辑与记忆。

## 📊 7 部白金神作的“绝对量化公约数”

基于对 7 部白金神作（超千万字切片样本）的 Python 自动化量化统计，本引擎固化了如下**黄金律动指标**：

| 关键指标 | 传统低质网文 | 白金级公约数标准 | 引擎硬性约束机制 |
| :--- | :--- | :--- | :--- |
| **平均段落长度** | 120 ~ 250 字（窒息大段） | **50 ~ 60 字** | 严禁出现 >120 字臃肿段落 |
| **短段落率 (<50字)** | < 25% | **> 50%** | 保持移动端极佳阅读呼吸感 |
| **全章对话占比** | > 60%（水字扯皮） | **26% ~ 36%** | 黄金分割：三成言语，七成世情推进 |
| **动作交织对话率** | < 30%（无头裸台词） | **> 75%** | 台词前后必绑定肢体微动作或道具交互 |
| **对话引导核心词** | 狂怒道/傲娇道/冷笑一声 | **`道` 与 `说` 占 90%** | 零度叙事，情绪收敛于正色/冷笑/失笑 |
| **打斗核心支点** | 漫天金光/神威盖世 | **受阻卡滞/器械形变/生理衰竭** | 必须描写骨缝卡滞、反震脱手与视线发黑 |

## 📦 开箱即用预设包 (Genre Presets)

系统内置 4 套开箱即用的题材预设，自动加载专属人物声纹、伏笔机制与冷却规则：

- 🏛️ **`history`（历史权谋）**：汉唐明清官制礼制、户部度支算学、士族豪强博弈、伪正史评注（参考《覆汉》《庆余年》）。
- ⚔️ **`xuanhuan`（高武变法）**：算学道法革新、神为民用、老实人反差天然黑、几何轨迹动能切割（参考《牧神记》）。
- 🏔️ **`xianxia`（凡人仙侠）**：古典修真、丛林资源竞争、低调谨慎实用主义、法宝灵药实物锚定（参考《凡人修仙传》《赤心巡天》）。
- 🎩 **`western_fantasy`（诡秘西幻）**：维多利亚蒸汽克苏鲁、序列扮演法、理智疯狂阈值、金镑物价经济学（参考《诡秘之主》）。

## 🚀 5 分钟快速上手

### 1. 克隆仓库与安装
```bash
git clone https://github.com/your-username/universal-novel-engine.git
cd universal-novel-engine
chmod +x bin/novel
```

### 2. 初始化你的第一部小说
选择题材预设（如历史权谋 `history`）：
```bash
./bin/novel init --genre history --dir ./my_novel
```
这会在 `my_novel/state/` 下自动生成：
- `character_registry.json`（人物声纹与习惯动作）
- `volume_outline.json`（分卷宏观大纲）
- `clues_ledger.json`（伏笔生命周期账本）
- `imagery_cooldown.json`（反套话冷却表）

### 3. 一键编译当前章生产级 Prompt
```bash
./bin/novel prompt 1 --dir ./my_novel
```
编译器将自动抓取上一章末尾物理尾流、检索在场人物状态、提取本章必须唤醒的伏笔、过滤冷却期词汇，生成一段极高确定性的工业级 Prompt。

### 4. 运行 18 项自动化质检与状态更新
将模型生成的章节正文送入质检机：
```bash
./bin/novel qa 1 --file ./my_novel/ch01.txt --dir ./my_novel
```
质检机将输出审查报告。如果通过，将**自动持久化正文、更新伏笔状态为 `watered`、将本章新用动词推入冷却期**：
```
=== 质检报告 ===
通过状态: ✅ 通过 (PASSED)
字数: 3520 字 | 段落均长: 54.2 字
短段落率: 52.1% | 动作交织率: 82.5%
具象物理词: ['骨', '崩裂', '受阻', '脱手']
状态: 零违规！伏笔已自动标记为 watered，冷却账本已更新，大纲第1章已标记 completed！
```

### 5. 查看进度总览
```bash
./bin/novel status --dir ./my_novel
```

## 🤖 Antigravity / Agent 装载方式

本项目原生兼容 **Google Antigravity** 与 **Claude Code** 标准技能系统：

1. **全局安装**：
   将本仓库复制或软链接至 Agent 技能目录：
   ```bash
   ln -s $(pwd) ~/.gemini/antigravity/skills/universal-novel-engine
   ```
2. **在对话中直接唤起**：
   在任何对话中输入：
   > *"加载 `universal-novel-engine` 技能，根据当前状态机为我生成第 5 章正文。"*
